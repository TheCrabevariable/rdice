# RDice
Rust Dice command for terminal.

Dependency ;

cargo

rust

To compile it you can clone the repo and use ;

``makepkg -si``

Have fun rolling the dice.



Troubleshot ;

``install: cannot stat 'target/release/rdice': No such file or directory``

It means it doesn't have eyes just compile it again and let it open his eyes.

Feel free to remove the files after compiling.
